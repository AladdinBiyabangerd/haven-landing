# Hook stilində video promptlar (AI Reel)

Bu sənəd **kod deyil**. Abstract hook → 5–7s vertical Reel. Caption = hook + guide link ([social-guide-hooks.md](social-guide-hooks.md)).

**Format:** 9:16 · 1080×1920 · 5–7s · səssiz də işləsin  
**Stil:** fotoreal, tünd klub, teal `#14B8A6`, chaos → order, tablet, Heselo mark  
**On-screen mətn:** yalnız Azərbaycan dili, ə/ç/ğ/ı/ö/ş/ü düzgün

### Shared negative (hər promptun sonuna yapışdır)

```
English headline, English UI (Live floor, Active, Schedule), cartoon, plastic CGI, purple neon cyberpunk, kitchen POS ticket spam, crowded sharp faces, watermark, misspelled Azerbaijani, garbled AI text, morphing letters, text flicker, shaky zoom spam, bland logo card, stock handshake
```

### Master şablon (hook dəyiş)

```
Photoreal cinematic vertical video 9:16 1080x1920, 6 seconds, curiosity Reel for entertainment club software. Smooth continuous motion. No cut spam.

CRITICAL — Azerbaijani on-screen text spelled PERFECTLY (ə ç ğ ı ö ş ü). Exact strings only. Sharp glyphs; no garbled AI text.

0.0–2.0s HOOK OPEN: [CHAOS VISUAL] — dark club atmosphere, tension, incomplete feeling. Soft bokeh, no sharp faces.

2.0–4.0s TRANSITION: chaos dissolves into teal #14B8A6 particles toward a real tablet on dark reception desk. Slow push-in, glass reflections.

4.0–6.0s HOLD: tablet with sparse Azerbaijani UI "Canlı zal" / teal accents. Heselo circular teal H + wordmark top corner, safe padding for Reels UI.

On-screen headline Azerbaijani only, large, bold, steady from 1.5s — exact:
"[HOOK LINE]"
Tiny subline exact (optional): "↓"

No English. Magazine-ad quality. Soft ambient haze. No voiceover.
```
